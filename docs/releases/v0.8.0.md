# Lecture Studio 0.8.0 — Campus Radar and evidence-backed lecture review

Lecture Studio now checks explicitly watched NU WeBWorK courses for unannounced
homework and observed deadline changes. Muse Spark separately helps review
assignment instructions and corrected deadlines in timestamped lecture text.

This is the first public release after 0.4.0 and includes the intervening
lecture-review, transcription and study-workflow improvements.

## What's new

- **Campus Radar:** opt into a course through the local Chrome extension. The
  desktop app records assignment observations, changed dates and availability,
  with source links, previous values and the last successful check.
- **Windows alerts:** one summary for the initial course baseline, then grouped
  alerts for observed changes. Repeated captures do not repeat the same alert.
  Disabled Windows notifications remain pending and are reported in the app.
- **Meta-powered Review:** Muse Spark extracts reviewable actions and deadline
  proposals from timestamped transcripts. Exact source references are checked
  locally. Assignment/date confirmation is required before a local deadline changes.
- **Versioned deadlines:** explicit corrections retain the previous version and
  update one active Inbox deadline. Durable recovery and revision checks protect
  against duplicate confirmations and stale overwrites.
- **Transcription:** recording starts saving audio while a cold local Whisper
  model prepares; saved timestamped transcripts reopen locally. Optional Muse
  Voice transport is available alongside Local Whisper, with language limitations.
- **Today and Academics:** review counts, approved study actions, flexible routine
  targets, inline raw scores and grade what-if controls. The advanced weekly view
  remains in More.
- **Optional executable lecture lab:** inspect a source-backed BFS interpretation,
  edit a small graph, step through traversal and compare hop count with weighted
  shortest-path cost. This is a bounded graph template, not arbitrary generated code.

## Install and connect

1. Download **LectureStudio-Windows-x64-20261028-213139.zip** and its `.sha256` file.
   Extract the whole `LectureStudio` folder and run `LectureStudio.exe`.
2. For Radar, download **CampusRadar-Chrome-0.1.0.zip** and its checksum, extract it
   to a permanent folder, and explicitly load that folder as an unpacked extension
   in Chrome's extension management page. Respect managed-browser restrictions.
3. In Studio, open **More → Campus Radar → Enable browser receiver** and copy the
   pairing code. Sign in to your course through Moodle in Chrome, open the
   extension, paste the code and choose **Watch this course**.
4. For lecture analysis, configure your own Meta Model API key in
   **More → Accounts & Setup**. No API keys or personal accounts are bundled.

Keep Studio, its enabled receiver, Chrome and a signed-in course tab running.
Enable the receiver again after reopening Studio. The extension schedules checks
about every five minutes; Chrome can delay them. Closing/sleeping apps stops coverage.
The extension does not install automatically with Studio.

Windows x64 is the packaged platform for this release. No 0.8.0 macOS binary is
attached. The Windows application is unsigned; checksums verify file integrity,
not publisher identity. Keep ordinary Windows security protections enabled.

## Verified for this release

- **440 Python tests** passed in isolated profiles and **12 Node adapter tests** passed.
- The actual frozen Windows build passed its fresh-profile self-test, including
  protected credential storage and all 13 workspaces.
- An owner-authorized real NU course produced six assignment observations.
  A later browser alarm checked the course automatically without creating
  duplicate events. Real student captures are excluded from public assets.
- Windows accepted a baseline notification request after the owner explicitly
  enabled tray messages. The rendered notification itself was not visually verified.
- Earlier live Muse Spark checks used authored English examples. The deadline
  correction workflow retained two versions and one active deadline. A frozen
  12-case development evaluation met 10 expectations and missed two candidates;
  this is not a classroom accuracy benchmark.

## Current boundaries

Radar supports the English NU WeBWorK course index and regular assignments.
Due dates and closing times remain distinct; unknown dates remain unknown.
Missing cards and failed checks never mean an assignment was completed.
Radar metadata stays on this computer and is not sent to Meta. Lecture text is
sent to Meta when the user requests analysis; optional cloud transcription sends
selected audio. Recordings and account data are not included in these downloads.

**Not connected yet:** Gmail, campus-opportunity ranking, automatic reconciliation
between WebWork and lecture sources, advance deadline reminders, or a general
multi-step AI agent. Mac device acceptance and full-class microphone/language
quality are separate from the Windows fixture checks.

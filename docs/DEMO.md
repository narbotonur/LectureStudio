# Portfolio demo

## One-line description

Lecture Studio is a local-first desktop workspace that turns recorded classes into
structured study material and connects that material to planning, grades, habits,
deadlines, and focused study time.

## 60-90 second walkthrough

1. **Problem (5 seconds).** "Lecture tools usually stop at transcription. I wanted
   one place that also helps me act on what I captured."
2. **Capture (15 seconds).** Open Notes, choose a class and microphone, start a
   recording, and point out the live audio meter and local Whisper transcription.
3. **Understand (15 seconds).** Show the transcript, personal highlights, generated
   study notes, flashcards, and the multi-file exam-prep flow.
4. **Plan (20 seconds).** Open Plan and show how fixed calendar events, prayer
   windows, Jumuah, habits, deadlines, credits, and grade gaps become a reviewable
   week without silently editing Google Calendar.
5. **Track (15 seconds).** Move through Study, GPA, and Habits. Emphasize active-only
   timer accounting and local persistence.
6. **Engineering (10 seconds).** Mention single-instance routing, background workers,
   OS credential storage, isolated tests, cross-platform packaging, and verified
   in-app updates.

## Recording checklist

- Use a fresh demo profile: never record a real calendar, email, course roster, or
  Moodle URL.
- Record at 1920x1080 or 1440p, 30 fps, with the OS cursor highlight disabled.
- Keep the app at 1280x800 so text remains readable after export.
- Use the fictional courses and schedule generated by `tools/capture_portfolio.py`.
- Trim pauses and loading screens; aim for 60-90 seconds.
- Export an H.264 MP4 under two minutes, upload it to the GitHub Release or a
  portfolio host, and link it from the README.
- Verify the final video frame by frame for notifications, account names, browser
  tabs, file paths, and calendar attendee information.

## Suggested portfolio copy

> I designed and built Lecture Studio, a cross-platform PyQt desktop application
> for lecture capture and study planning. The app combines local Whisper
> transcription, review-first AI workflows, calendar-aware weekly planning, grade
> and habit tracking, a quiet meeting watcher, secure per-user credentials, and
> verified updates. I separated domain logic from the UI, added isolated tests and
> reproducible release builders, and ported the native packaging path to macOS.

## Rebuild the media

From the repository root:

```powershell
python tools/capture_portfolio.py
python tools/audit_public_repo.py
```

The first command recreates the four PNGs and the animated GIF in `docs/assets`
from a temporary fictional profile. The second checks that the generated public
tree does not contain common credential values or private data files.
